## Problema y propuesta

Organizar encuentros deportivos amateur suele depender de mensajes dispersos y datos incompletos sobre rivales, integrantes, disponibilidad y asistencia. RivalMatch propone centralizar el proceso de búsqueda, solicitud, confirmación y seguimiento de partidos para facilitar la coordinación de jugadores y equipos.

La solución considera una app móvil para usuarios finales y componentes de servidor y persistencia para gestionar perfiles, equipos, encuentros, solicitudes, cupos, reputación y estadísticas deportivas. Las funciones verificadas deben distinguirse de las que aún requieren pruebas integrales.

## Tecnologías del prototipo

- **Móvil:** React Native, Expo y TypeScript.
- **Backend:** Node.js, Express, TypeScript, API REST y JWT.
- **Base de datos:** PostgreSQL, Prisma y Docker (entorno local).
- **Prototipo web:** React y Vite, cuando corresponde a los módulos del proyecto.

## Metodología

Se emplea la **metodología en cascada**: levantamiento de requerimientos, diseño, implementación, verificación, entrega y mantenimiento posterior. Las plantillas denominadas "Sprint Backlog" y "Retrospectivas" se utilizan como evidencias de seguimiento, sin declarar que el proyecto se desarrolló bajo Scrum.

## Estructura de evidencias

### [Fase 1 – Definición del Proyecto APT](Fase%201/)

- `Evidencias Grupales`: Product Vision, definición del proyecto, informe de apoyo y presentación de la idea.
- `Evidencias Individuales`: tres documentos por integrante (nueve en total).

### [Fase 2 – Desarrollo del Proyecto APT](Fase%202/)

- `Evidencias Grupales`: guía de avance e informe de desarrollo.
- `Evidencias Individuales`: tres documentos por integrante (nueve en total).
- `Evidencias de documentación`: UML, modelo de datos, requisitos no funcionales, plan de trabajo y matriz de pruebas.
- `Evidencias de sistema`: aplicación, base de datos y Docker.

### [Fase 3 – Presentación del Proyecto APT](Fase%203/)

- `Evidencias Grupales`: presentación de 16 diapositivas y guion de 20 minutos.
- `Evidencias Individuales`: diario de reflexión `3.1` y autoevaluación `3.2` para cada uno de los tres integrantes (seis documentos).
- `Evidencias Proyecto`: referencia a la presentación y lista de verificación para la defensa.
